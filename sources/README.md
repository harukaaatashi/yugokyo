# 一次資料の出典とライセンス

## sources/ndl/ — 『洗湯手引草』全38コマ

- 出典: 国立国会図書館デジタルコレクション『洗湯手引草』
  - https://dl.ndl.go.jp/pid/2539997
  - 向晦亭等琳 著、嘉永4年（1851）刊
- 利用条件: **保護期間満了（パブリックドメイン）**。NDLの利用規定により転載自由。
  サイト掲載時は出典「国立国会図書館デジタルコレクション」を明記する。
- 取得方法: `npm run fetch:sources`（IIIF Image API経由）

## 照合用（画像は保存・転載しない）

- 国書データベース『湯語教／一名銭湯手引草』（東書文庫蔵）
  - https://kokusho.nijl.ac.jp/biblio/100266100/
  - DOI: 10.20730/100266100
  - 利用条件が東書文庫の規定に従うため、**読み比べの参照のみ**に使う。
    画像ファイルの保存・サイトへの転載はしない。

『湯語教』と『洗湯手引草』は同一作品（「湯語教 一名 銭湯手引草」）。
NDL本の題箋が「洗湯手引草」、東書文庫本の内題が「湯語教」。
