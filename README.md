# 湯語教（ゆごきょう）を読む

江戸の銭湯経営手引書『湯語教／一名 銭湯手引草』（向晦亭等琳・嘉永4年 / 1851）を、
原本画像・翻刻・現代語訳の三段で読める対訳リーダー。

くずし字が読めなくても、170年前の銭湯経営の教科書を最初から最後まで読み通せます。

## この本について

「日本最古の銭湯経営の手引書」として知られる本です。国立国会図書館の所蔵本は
外題から『洗湯手引草』、東書文庫の所蔵本は『湯語教』の名で登録されていますが、
**どちらも同じ本**（内題「湯語教 一名 銭湯手引草」）です。

収録内容:

- **序** — 「銭湯に五常の道あり」。裸になれば身分の上下なし、という江戸の銭湯讃歌
- **洗湯之由来** — 光明皇后の千人施浴伝説
- **湯語教** — 寺子屋の教科書『実語教』のパロディ韻文。
  「湯屋磨かざれば光沢なし、光なければ常に客入らず」
- **湯屋番組大意** — 文化7年（1810）に町奉行所公認。江戸の湯屋は全620株
- **湯屋万歳暦** — 湯女の禁止、湯銭の変遷、寛政3年の混浴禁止、天保の改革
- **証文ひな形集** — 湯屋の売買、敷金、奉公人請状
- **薪の相場表**と**三宝日の暦**

## 翻刻について

**翻刻・現代語訳はAI（Claude）による下訳で、未校正です。** 誤読が含まれます。
読みが不確かな箇所は本文中で下線をつけて明示し、判読不能な字は 〓 で示しています。
研究・引用の際は必ず原本画像をご確認ください。

## 開発

```bash
npm install
npm run dev          # 開発サーバー
npm run build        # ビルド
npm run typecheck    # 型チェック
npm run check:corpus # 翻刻データの整合チェック
npm run fetch:sources # NDLから原本画像を再取得
```

- 翻刻データは `corpus/koma-XX.json`（1見開き＝1ファイル）
- UIルールは `DESIGN.md` が唯一の正
